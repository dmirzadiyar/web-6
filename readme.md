## PART 2. jQuery Effects

### Task 2. Visibility Methods

I created an About Me section with a short biography, current status, and fun facts. I used .hide(), .show(), and .toggle() to control the visibility of the content.

### Task 3. Fade Methods

I created an image gallery with at least two images. I used .fadeIn(), .fadeOut(), and .fadeToggle() to control image visibility with smooth transitions.

### Task 4. Slide Methods

I created three collapsible sections about my favorite music, movie, and subject. I used .slideUp(), .slideDown(), and .slideToggle() to make the panels open and close smoothly.

## PART 3. DOM Manipulation with jQuery

### Task 5. Add and Remove Elements

I created a list containing technical skills and an input field for adding new skills. I used .append(), .prepend(), and .remove() to manage the list and prevented empty skills from being added.

### Task 6. Modifying Attributes

I added a social media link to my portfolio and created a button to change its destination dynamically. I used the .attr() method to modify the link URL.

### Task 7. Form Interaction

I created a form with Name and Email inputs. I used .val() to get the entered values and .text() to display them live below the form.
